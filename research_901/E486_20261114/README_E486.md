## 2. 本轮真正新增的推导：观测通道误差带来的明确不可辨识范围
设 A 为分裂前可核的母体老/新极类别；Y 为分裂后观察到的“新极女儿更亮”的二值指示；T 为同一时点真实但未标定的亮度胜者（二值潜变量）。E485冻结经验值 I(A;Y)=0.02290337098 bit/姐妹对。

**仅作条件敏感性模型**：假定每一类别共享同一、与A及真实T独立的对称错分率 ε，且 0≤ε<1/2：
P(Y=1|A=a) = ε + (1−2ε) P(T=1|A=a)。
因此真实二值类别条件概率若在[0,1]，就有
0≤ε≤ min_a {q_a,1−q_a} = 31/178 = 0.174157303371，
其中 q_new=119/177、q_old=147/178。
所有该范围的 ε 给出**完全相同的已经观察到的2×2频率**；在相应模型内潜在 I(A;T) 从 ε=0 的 0.02290337098 增大至 ε=31/178 的 **0.12931534899 bit/姐妹对**。这是一个由已有数据求出的**条件模型集合**，不是实测生化信息范围、不是统计置信区间，也没有替成像系统挑选一个参数。

严格性理由：较高ε的潜在二值变量可再经一个对称二元通道退化为较低ε的潜在变量；数据处理不等式保证该假设族内互信息单调。两端构造的观察分布相同，因而**现有E485输出不能点识别真实亮度状态的MI**，更不能点识别分裂前实际物质拷贝与分裂后女儿物质拷贝的传递信息。可能的老极年龄、报告器表达、光学漂移或分配机制也不由该模型隔离。

**物理转运的正式目标**是I(分裂前同一母体真实分子状态;分裂后核定身份女儿真实分子状态 | 培养条件/时钟/空间共因)，若做因果声明还需独立干预。A是母体类别、T只是二元相对亮度；两者不能充当真实拷贝计数。实际传输bit = NOT_IDENTIFIED；本轮没有提供其数值上界/下界。

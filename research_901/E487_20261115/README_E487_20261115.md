核心课题是生命内部信息如何被保留/传递、生命之间外部信息量、以及能量和时钟的同一物理口径。本阶段针对E486识别门扩展**独立公开实验真实单细胞母女身份数据**，不以换一套数据集就把观测互信息冒充真实分子传输bit。E478–E486的全部旧实证、阴性、冻结和论文投稿状态不改动；本轮不重复运行旧源。

## 3. E487新增观测信息量：有真实身份、但不是分子bit

冻结事件单位为**同一母体分裂所生的两位女儿**。对每组取分裂前母体最后有记录的一帧荧光幅度`M`，两女儿出生后第一有记录帧的荧光幅度`D_top,D_bottom`，定义`D_sum=D_top+D_bottom`。只有所有幅度>0进入。对每个候选实验日期分别编码`X=quartile_date(log M)`，`Y=quartile_date(log D_sum)`，四档切点来自该日期实际样本；各日期内经验互信息用**实际事件数**加权：

\[
\widehat I_{\mathrm{within-date}}=\sum_{d=1}^{27}rac{n_d}{42694}\sum_{x,y=0}^3\widehat p_d(x,y)\log_2rac{\widehat p_d(x,y)}{\widehat p_d(x)\widehat p_d(y)}.
\]

**E487真正新实算结果：`1.3362566424874205 bit/严格母女分裂观测事件`**（27个不同处理条件中的日期内加权、样本后切点的离散经验MI）。日期级MI中位约1.300227、范围0.738089–1.828023 bit；这些日期不是同一总体或随机实验的无条件抽样。27个日期逐日起点不一，不可直接外推统一物种常数。两女儿荧光总幅度/母体末帧幅度的每日期中位数约0.993–1.051；它显示观测量的跨分裂连续性，但**不等于分子数守恒**, 也不等于生物体新增信息或复制保真率。

**强共因与错配负对照**：保持日期、lane和局部帧阶段不变，仅在20/40/80帧宽度内打乱女儿总幅度与母体身份；300次不同置乱（固定种子）得到的日期内加权MI技术参照中位数分别为**0.930141 / 0.758736 / 0.510639 bit**，观察值1.336257bit均更大。不同错配窗口的基线本身差异巨大，说明时间背景、同lane细胞相关性和统计设计对估计很敏感；观测减置乱中位数的0.406/0.578/0.826 bit **不能叫去偏后的物理信号传输bit**。置乱仅打乱实验观察对应，不是独立控制培养基/光漂白/相机噪声的真正随机试验；非随机生物学p值。

同样**不能将1.336bit与E485的0.0229bit、E482的老极掩膜MI或基因组固定编码bit相加**：它们来自不同研究、不同定义和测量口径。实际独立母女分子状态联合分布、蛋白传递通道、物理分子拷贝数、完整生命周期去重总账仍NOT_IDENTIFIED；不输出bit/s或bit/J。
